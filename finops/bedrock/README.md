# 📌 About This Experiment

This folder contains an **experimental AWS Bedrock integration** designed to evaluate how Generative AI could be used to analyze AWS cost data and provide FinOps recommendations.

The experiment combines:

```text
💰 AWS Cost Explorer
        ↓
⚡ AWS Lambda
        ↓
🐍 Python Cost Analysis
        ↓
🧠 Amazon Bedrock
        ↓
🤖 AI-Based Cost Analysis
        ↓
💡 Optimization Recommendations
